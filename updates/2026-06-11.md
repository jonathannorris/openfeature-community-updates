### Proposals to watch
- **[spec#390](https://github.com/open-feature/spec/issues/390): Flag distribution layer & observability** (opened Jun 10). OpenFeature standardizes how a single evaluation is reported, but says nothing about the set of flags available to a service. This proposes a provider-neutral data model for that inventory (defaults, variants, enabled state, flag-set membership, version) and an emitter-agnostic way to observe it.
- **[spec#389](https://github.com/open-feature/spec/pull/389): Spec compliance GitHub action** (open). A reusable action for SDK repos that validates test coverage against the spec, intended as a required check for 1.0+ SDKs.
- **[flagd#1979](https://github.com/open-feature/flagd/pull/1979): Numeric coercion proposal** (open). Defines numeric coercion behavior and IEEE-754 safe-integer limits across all flagd implementations, tracking [flagd#1978](https://github.com/open-feature/flagd/issues/1978).

## Disabled flag evaluation (`reason=DISABLED`)

Umbrella issue: [flagd#1965](https://github.com/open-feature/flagd/issues/1965), closed in this window. Evaluating a disabled flag used to return an error with `FLAG_DISABLED`, which is not a valid error code in the OpenFeature spec or in OFREP. Disabled flags now resolve successfully with `reason=DISABLED` and still return the caller's default value, so the break is only visible to code that inspects `reason` or `errorCode`.

**Shipped:** flagd core, gRPC, and OFREP layers ([flagd#1968](https://github.com/open-feature/flagd/pull/1968)) · testbed scenarios ([flagd-testbed#376](https://github.com/open-feature/flagd-testbed/pull/376)) · in-process providers for Go ([go-sdk-contrib#896](https://github.com/open-feature/go-sdk-contrib/pull/896)), JS ([js-sdk-contrib#1558](https://github.com/open-feature/js-sdk-contrib/pull/1558)), Java ([java-sdk-contrib#1800](https://github.com/open-feature/java-sdk-contrib/pull/1800)), Python ([python-sdk-contrib#395](https://github.com/open-feature/python-sdk-contrib/pull/395)), and .NET ([dotnet-sdk-contrib#671](https://github.com/open-feature/dotnet-sdk-contrib/pull/671)).
