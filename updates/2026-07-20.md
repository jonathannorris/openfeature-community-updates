# OpenFeature Community Update: Jul 6 to Jul 20, 2026

_A biweekly digest of the most notable pull requests, issues, and discussions across the [open-feature](https://github.com/open-feature) org._

## TL;DR

- **Numeric coercion contract is rolling out.** With the ADR merged in flagd, tracking issues landed across every provider contrib repo on Jul 13 — a coordinated breaking change capping numeric variants at IEEE-754 safe-int range ([flagd#1995](https://github.com/open-feature/flagd/issues/1995), [flagd#1996](https://github.com/open-feature/flagd/issues/1996), plus six more repos).
- **flagd 0.16.0's DISABLED semantics are causing cross-SDK friction.** The "DISABLED is a successful evaluation" change is not consistently handled across provider SDKs; PHP provider has a fix in progress ([flagd#1997](https://github.com/open-feature/flagd/issues/1997), [php-sdk-contrib#172](https://github.com/open-feature/php-sdk-contrib/pull/172)).
- **OFREP Cloudflare Worker gained SSE event stream support** per ADR-0008, making real-time flag change delivery available to CF Workers deployments ([flagd-ofrep-cf-worker#39](https://github.com/open-feature/flagd-ofrep-cf-worker/pull/39)).
- **The C++ SDK is accelerating** with hooks infrastructure merging (HookData, HookContext, base structures), a v0.1.2 release, and several new PRs in flight.
- **spec#408 shipped** post-merge clarifications on event-driven provider status, addressing ordering ambiguities and spontaneous events from spec#385 ([spec#408](https://github.com/open-feature/spec/pull/408)).

## Cross-SDK: Numeric coercion contract

The numeric coercion ADR (merged in [flagd#1979](https://github.com/open-feature/flagd/pull/1979) in late June) is now being implemented across the ecosystem. On Jul 13, `toddbaert` filed coordinated tracking issues across every affected repo:

- **Contract:** numeric variants are returned via a numeric accessor only when the conversion is lossless; otherwise `TYPE_MISMATCH`. Numeric flag values are capped at the IEEE-754 safe-integer range.
- **Flagd & infra:** [flagd#1995](https://github.com/open-feature/flagd/issues/1995) (implement ADR) · [flagd#1996](https://github.com/open-feature/flagd/issues/1996) (breaking variant) · [flagd-schemas#219](https://github.com/open-feature/flagd-schemas/issues/219) · [flagd-testbed#379](https://github.com/open-feature/flagd-testbed/issues/379)
- **Provider contrib repos:** [js-sdk-contrib#1578](https://github.com/open-feature/js-sdk-contrib/issues/1578) · [java-sdk-contrib#1822](https://github.com/open-feature/java-sdk-contrib/issues/1822) · [go-sdk-contrib#923](https://github.com/open-feature/go-sdk-contrib/issues/923) · [python-sdk-contrib#402](https://github.com/open-feature/python-sdk-contrib/issues/402) · [dotnet-sdk-contrib#709](https://github.com/open-feature/dotnet-sdk-contrib/issues/709) · [php-sdk-contrib#169](https://github.com/open-feature/php-sdk-contrib/issues/169) · [rust-sdk-contrib#151](https://github.com/open-feature/rust-sdk-contrib/issues/151)

This is a `feat!` (breaking) change for most provider implementations.

### flagd
- **[flagd-ofrep-cf-worker#39](https://github.com/open-feature/flagd-ofrep-cf-worker/pull/39) (merged):** SSE event streams are now supported in the OFREP Cloudflare Worker, implementing ADR-0008 (protocol#63). Paired with the v0.0.5 automated release.

- **Concurrency fixes:** [flagd#1993](https://github.com/open-feature/flagd/pull/1993) prevents send on closed channel in `EmitToAll`; [flagd#1994](https://github.com/open-feature/flagd/pull/1994) fixes a re-check race in the cert reloader.
- **[flagd#1997](https://github.com/open-feature/flagd/issues/1997) (issue, 2 comments):** The flagd 0.16.0 change treating `DISABLED` as a successful evaluation (reason=`DISABLED`, no value/variant) is not consistently implemented across provider SDKs, and was not called out as a breaking dependency in the release notes. PHP provider has an active fix at [php-sdk-contrib#172](https://github.com/open-feature/php-sdk-contrib/pull/172).
